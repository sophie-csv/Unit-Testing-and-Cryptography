# Unit Testing & Cryptography

A Python project developed as part of a coding application class. Created 8 cryptography methods (4 functions having an encode and decode method) and unit-tested each to ensure functionality.

## Features
### Part 1
 Ceasar Shift (encode & decode)
 Substitution Cipher (encode & decode)
Unit Testing for each method

### Part 2
Vigenere Cipher (encode & decode)
Affine Cipher (encode & decode)
Unit Testing for each method
